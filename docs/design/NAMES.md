Criteria, as for Kerix: short Greek-rooted name with a persona; pronounceable and spellable after hearing it once; not crowded on GitHub; no well-known app or AI company with the same name. Themes: ownership, one's own hearth, self-rule, the steward who keeps the keys, the one who weighs and measures. Crowding = GitHub repositories with the word in the name; npm and crates.io checked by registry lookup (free means no package of that name).
